# Реверс-инжиниринг монитора MSI MPG 341CQPX QD-OLED

Исследование прошивки и железа монитора MSI MPG 341CQPX QD-OLED: как скалер
управляет QD-OLED панелью, как устроены загрузка, обновление и отладочные
консоли, какие протоколы идут по USB, UART и DDC. Рядом — собственные свободные
прошивки: первичный загрузчик 8051 с автономным восстановлением по USB и
приложение USB-моста `U7005`.

**Платформа:** скалер Novatek **NT68503**, панель **SDC QMC340CA01_D01** (Samsung
QD-OLED второго поколения, 3440×1440, 240 Гц). Образ прошивки MSI не сжат и не
зашифрован.

Исследование продолжается. Документы написаны по-русски; английский в основных
файлах появится позже.

## Что это за репозиторий

Это **публичная редакция**. Исследование ведётся в закрытом репозитории, а сюда
регулярно выгружается разрешённая часть. Намеренно отсутствуют:

- **образы прошивок MSI и дампы микросхем** — файлы MSI скачиваются с сайта MSI
  (ниже), дампы относятся к конкретному экземпляру;
- **сырые захваты** логического анализатора и USB — в них код и данные MSI;
- **материалы, опирающиеся на закрытую документацию**;
- **собственные прошивки Leon2 Main и STBC** и документы о них — работа идёт,
  они появятся позже.

Ссылки на неопубликованные файлы в документах заменены текстом с пометкой
«(не опубликовано)».

Вклад приветствуется: issues и pull requests. Принятый PR переносится в
исследовательский репозиторий и возвращается сюда со следующей выгрузкой.

## Устройство монитора

Четыре ядра в одном кристалле делят один образ на SPI-флеше `U4002`: 8051,
Tensilica Xtensa и два SPARC v8 big-endian (Leon2 Main и Leon2 Sub). 8051 владеет
флешем и кнопками, Leon2 Main — меню, прикладной логикой и I²C к панели, Leon2 Sub —
видеовходами. Данные экземпляра — серийный номер, наработка, калибровка —
хранятся в I²C EEPROM `U4003`, а не во флеше.

| Образ | ISA | База | Где в файле FW.037 |
|---|---|---|---|
| STBC | 8051 | `0x0000` | `0x000000–0x02E600` |
| Tensilica | Xtensa LE | `0x40000000` | `0x030000–0x03D8DC` |
| Leon2 Sub | SPARC v8 BE | `0xA0060000` | `0x050000–0x0A5600` |
| раздел `id=0x0B` (тракт HDR) | SPARC v8 BE | `0x9F1B0000` | `0x0B0000–0x0CF500` |
| раздел `id=0x0D` (runtime Main) | SPARC v8 BE | `0xA0028000` | `0x0D0000–0x0D80C8` |
| Leon2 Main | SPARC v8 BE | `0x00000000` | адрес 0 = файл `0x108000` |

Подробно и с доказательствами — [карта прошивки](docs/firmware-map.md).

## Инструменты и сборка

Python — только из локального окружения:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install pyserial -r tools/requirements-u7005.txt
```

```sh
.venv/bin/python tools/fwmap.py MSI_MPG_341CQPX_QD-OLED_FW.037_0225.bin -o out/  # разделы и регионы
.venv/bin/python tools/edid.py MSI_MPG_341CQPX_QD-OLED_FW.037_0225.bin             # EDID, CTA-861, DisplayID
.venv/bin/python tools/uart_text.py CAPTURE.txt                                   # захват UART → текст
.venv/bin/python -m pytest -q tools                                               # тесты инструментов
make -C firmware/bootloader-libre verify   # сборка и проверка загрузчика (нужны SDCC и файлы MSI)
make -C firmware/u7005 verify              # сборка и проверка моста (нужен Arm GNU Toolchain)
```

Скрипты Ghidra — в `tools/ghidra_scripts/`, импорт образов — `tools/ghidra_import.sh`
(Ghidra 12, JDK 21+), имена функций — в `names/`. Среда разработки `U7005` описана в
[docs/u7005-development.md](docs/u7005-development.md).

Собственные прошивки:

- [`firmware/bootloader-libre/`](firmware/bootloader-libre/) — свободный первичный
  загрузчик 8051 на SDCC. Штатно запускает прошивку, а при удержании джойстика
  вправо поднимает USB ISP без основной прошивки: через него читается и пишется
  весь `U4002`.
- [`firmware/u7005/`](firmware/u7005/) — собственное приложение моста USB–I²C/UART
  на NUC1261, совместимое с утилитой MSI.
- [`firmware/platform/`](firmware/platform/) и [`firmware/protocols/`](firmware/protocols/) —
  общие определения регистров и описания протоколов.

## Риск для монитора

Всё здесь проверено на одном экземпляре. Инструменты записи (`tools/isp_write.py`,
установка `bootloader-libre` и прошивки `U7005`) могут сделать монитор
неработоспособным; при повреждении области загрузчика восстановление возможно
только программатором SPI-флеша. Перед любыми опытами снимите полный дамп `U4002`
и `U4003`. **`U4003` хранит уникальные данные экземпляра — не пишите в него.** Не
отключайте защиты OLED-панели: это ведёт к ускоренному выгоранию. Вскрытие монитора
может лишить гарантии. Всё — на ваш риск, без гарантий.
